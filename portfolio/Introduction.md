## Introduction

I tested my own Poker Game that runs on Command Line Interface (CLI). It runs with one user (the player) against 8 bots. The game starts everyone with 1,000 chips with blinds raising as the rounds go on. The program deals each hand, enforces betting rules, calculates main and side pots, ranks hands to determine winners, and eliminate players who run out of chips. The bots have three play styles (passive, balanced and aggressive). The program also calculates winning hand probabilities using Monte Carlo Simulation. The program is a good test subject because it uses exact rules (pots, hand, ranking), probability and time limits.
