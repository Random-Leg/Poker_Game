## Introduction

I tested my own Poker Game that runs on a command line interface (CLI). It runs with one user (the player) against 8 bots. The game starts everyone with 1,000 chips with blinds rising as the rounds go on. The program deals each hand, enforces betting rules, calculates main and side pots, ranks hands to determine winners, and eliminates players who run out of chips. The bots have three play styles (passive, balanced and aggressive). The program also calculates winning hand probabilities using Monte Carlo Simulation.

Repo Link: https://github.com/Random-Leg/Poker_Game

Detailed docs for each LO can be found in the repo under `docs/*`.
